Diversification in OCBILs: tracing the evolutionary history of a frog clade that is endemic to campo rupestre

Description of the data and file structure
Files and variables
File: BioGeoBEARS.zip
Description: folder containing the archives used in BioGeoBEARS analysis. The folder contains the following archives:
    • 1_BioGeoBEARS_model_selection_unconstrained.R
      Description: BioGeoBEARS script from Magalhaes et al. (2021) used to select the best model between DEC, DIVA-like, BAYAREA-like, DEC+J, DIVA-like+J and BAYAREA-like+J.
    • 2_Biogeobears_BSM_boker.R
      Description: script from Magalhaes et al. (2021) used to estimate ancestral ranges over a distribution of trees using BioGeoBEARS, counts lineages in areas through time, identify most common transitions, and estimates the timing of transitions by using biogeographic stochastic maps (BSM). BSM analyses performed for the selected model (DIVA-like+J).
    • boker.tree
      Description: Input tree used for BioGeoBEARS analyses.
    • boker_geog.txt
      Description: BioGeoBEARS input file with species biogeographical ranges. 
      Variables: Species codes used: balva (Bokermannohyla alvarengai); bsaxi (B. saxicola); bnanu (B. nanuzae); bmarti (B. martinsi); bastar (B. astartea); bcarva (B. carvalhoi); bhyla (B. hylax); bdiam (B. diamantina); bibit (B. ibitiguara); bflavo (B. flavopicta); bita (B. itapoty); bjui (B. juiju); boxeh (B. oxente - Lineage 1); boxei (B. oxente - Lineage 2); boxej (B. oxente - Lineage 3); bpseu (B. pseudopseudis); bsapid (B. sapiranga - Lineage 1); bsapie (B. sapiranga - Lineage 2); bsapif (B. sapiranga - Lineage 3).
    • File: boker_trees.nex
      Description: *Beast output used to sample trees in BioGeoBEARS and BSM analyses.
    • File: sample_trees.zip
      Description: 100 trees sampled from *Beast output used in BioGeoBEARS and BSM analyses.
File: partitionfinder.zip
Description: folder containing the archives used in Partition Finder analysis. The folder contains the following archives:
    • File: partitionfinder_boker.phy 
      Description: genetic dataset.
    • File: partition_finder_boker.cfg 
      Description: parameters and priors.
File: mrbayes_boker.nex
Description: genetic dataset, parameters and priors used in MrBayes analysis.
File: raxml_boker.phy
Description: genetic dataset used in RAxML analysis.
File: starbeast_boker.xml
Description: genetic dataset, parameters and priors (xml generated in BEAUti) used to infer a species tree with *BEAST according to BPP population assignment.
File: BPP.zip
Description: folder containing the archives used in BPP analyses. The folder contains the following archives:
    • Files: A11_boker_1_alg0.ctl; A11_boker_1_alg1.ctl; A11_boker_2_alg0.ctl; A11_boker_2_alg1.ctl; A11_boker_3_alg0.ctl; A11_boker_3_alg1.ctl; A11_boker_4_alg0.ctl; A11_boker_4_alg1.ctl
      Description: parameters and priors of each analysis. 
    • File: genetic_matrix.txt
      Description: the genetic dataset.
    • File: heredity.txt
      Description: the heredity multipliers.
    • File: imap.txt
      Description: file containing the names of sequences and the corresponding numbers in genetic dataset .
File: Genbank.zip
Description: folder containing alignments of gene fragments used for phylogenetic analyses. The folder contains the following archives:
    • File: Bfib.fas
      Description: alignment of β-fibrin7 gene fragment.
    • File: Cmyc.fas
      Description: alignment of C-myc2 gene fragment.
    • File: Coi.fas
      Description: alignment of COI gene fragment.
    • File: Tensin.fas
      Description: alignment of TNS3 gene fragment.
    • File: Tyr.fas
      Description: alignment of TYR gene fragment.
